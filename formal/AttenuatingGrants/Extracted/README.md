# Extracted evaluator (generated)

`GrantEval.lean` is the Lean translation of `crates/grant-eval`, generated by
`formal/scripts/extract.sh` with the pinned Charon and Aeneas: Charon
translates the crate to LLBC, Aeneas translates the LLBC to Lean. Do not edit
it by hand; change the Rust and re-run the script.

CI re-runs the extraction (`formal/scripts/extract.sh --check`) and fails if
the result differs from the files here. `formal/AttenuatingGrants/Equiv/`
proves that this code agrees with the readable model; `formal/README.md`
describes the pinned versions and the theorems.
