## T-sdk-F2 — lowerDoc, documented as a 'faithful mirror' of the Rust compiler that 'fails closed', accepts documents perch_ir::validate refuses (and refuses one it accepts)

- Source: T-sdk (finding)
- Jev improves: 0.94
- Jev defect / severity: requirement_or_code / medium
- Locations: nido/packages/passkey-sdk/src/policyDoc/lower.ts:1-25, nido/packages/passkey-sdk/src/policyDoc/lower.ts:63-143, nido/packages/passkey-sdk/src/policyDoc/lower.ts:164-187, nido/vendor/perch/crates/perch-ir/src/validate.rs:674-972

The on-chain compiler runs perch_ir::validate before compile(). lowerDoc only checks duplicate signer ids, duplicate rule names, empty principals, the threshold range, not-after-ledger >= 1 and the cap. A Rust-vs-TS differential (1500 random documents, replayed through perch-ir) found 273 documents that lowerDoc lowers into an install plan and Rust rejects. The rejections cover 25 ValidationError variants: DuplicatePrincipalSigner (e.g. all:[a,a] -> MinSigners(2) over the same signer twice), DuplicateSignerKey (one key or address under two ids, including hex-case variants -> a '2-of-2' over one physical key), EmptyFunctions (functions:[] -> FnIn([]) deny-all), InvalidFunctionName, DuplicateArgIndex, EmptyArgs, EmptyStringInValues, SignerKeyLength, InvalidSignerKeyHex, InvalidContractAddress (G-address scope), InvalidArgAddress, EmptyRuleName/EmptySignerId, and every recovery check (EmptyRecoveryReplaceable, InvalidGuardianQuorum, Zero*Ledgers, ZeroRecoveryMaxCancels). In the other direction, cap.limit '+5' is valid for Rust (str::parse::<i128> accepts a leading '+') but lowerDoc's /^[0-9]+$/ refuses it. The canonical form, rule hashes and recovery canonical form agreed on every vector.

**Recommendation:** Either port perch_ir::validate's rule, signer and recovery checks into lowerDoc (or a shared validateDoc() used by buildPolicyDoc and buildApplyDocTx too), and parse cap.limit with i128 semantics including a leading '+'. Or drop the 'faithful mirror / fails closed' claim and mark lowerDoc preview-only. Keep the differential harness (out/repro/differential) in CI.
