## T-sdk-F6 — recoverySpec defaults `replaceable` to ['owner'] while the SDK's own baseline names the admin signer 'admin'; quorum range unchecked

- Source: T-sdk (finding)
- Jev improves: 0.92
- Jev defect / severity: requirement_or_code / medium
- Locations: nido/packages/passkey-sdk/src/perch/doc.ts:54-55, nido/packages/passkey-sdk/src/perch/doc.ts:66-102, nido/packages/passkey-sdk/src/perch/doc.ts:136-140, nido/vendor/perch/crates/perch-ir/src/validate.rs:1003-1019

recoverySpec says it 'Throws when the mode's required parts are missing, before the compiler would'. But replaceable defaults to ['owner'], while Nido's convention (adminBaseline, renameLegacyOwner in the wallet) declares the founder passkey as 'admin'. withRecovery only shape-checks (parsePolicyDoc), so it returns a document whose recovery.replaceable names an undeclared signer; perch_ir::validate refuses it (UnknownRecoveryReplaceableRef). recoverySpec also accepts quorum > guardians.length, which validate_guardian_set refuses (InvalidGuardianQuorum).

**Recommendation:** Drop the default (require replaceable), or default to the doc's admin signer id. In recoverySpec, check 1 <= quorum <= guardians.length. In withRecovery, check that every replaceable id is declared in doc.signers.
