## T-sdk-F3 — SDK builds and submits documents without `network` although the compiler refuses every such document (WrongNetwork)

- Source: T-sdk (finding)
- Jev improves: 0.97
- Jev defect / severity: requirement_or_code / medium
- Locations: nido/packages/passkey-sdk/src/policyDoc/build.ts:56-67, nido/packages/passkey-sdk/src/policyDoc/build.ts:78-129, nido/packages/passkey-sdk/src/policyDoc/applyDoc.ts:62-75, nido/vendor/perch/crates/perch-doc-compiler/src/lib.rs:435-444

perch-doc-compiler compile_parsed does `doc.network.as_ref().ok_or(WrongNetwork)`, so a document without network can never be applied. buildPolicyDoc and scopedSessionKeyDoc make network optional. buildApplyDocTx only compares a network that is present (`doc.network !== undefined && ...`), then simulates.

**Recommendation:** In buildApplyDocTx, refuse doc.network === undefined with a clear message (and/or make `network` required in buildPolicyDoc/scopedSessionKeyDoc).
