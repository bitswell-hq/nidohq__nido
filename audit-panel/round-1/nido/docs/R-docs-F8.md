## R-docs-F8 — The deployment test never reads the documented Nido factory address

- Source: R-docs (finding)
- Jev improves: 0.94
- Jev defect / severity: description_only / medium
- Locations: nido/DEPLOYED.md:22-25, nido/docs/SECURITY_INVARIANTS.md:146, nido/packages/passkey-sdk/src/perch/deployment.test.ts:8-17, nido/packages/passkey-sdk/src/perch/deployment.ts:80-83

DEPLOYED.md and W6 say deployment.test.ts takes Nido's factory address from the deployment record. The test reads only Perch's JSON manifest, passes TESTNET.factory into fromPerchManifest, and compares the result with TESTNET. fromPerchManifest copies that argument unchanged. No deployment record is read, so the factory comparison is tautological. W6 correctly disclaims independent factory verification, but still incorrectly claims a record-to-code comparison.

**Recommendation:** Load Nido's factory address from a separate machine-readable deployment record and compare it with TESTNET.factory, or state explicitly that the test excludes the factory field and does not check this documentation.
